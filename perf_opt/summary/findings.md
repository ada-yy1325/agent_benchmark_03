# Findings: 阶段 1 性能画像分析

## 矩阵规划（步骤 1.1）

### 执行优先级
1. **4K 档（输入 4096）** — 最先跑，最接近真实场景（GPQA 平均输入 ~250 tok，但长输入压力更大）
2. **2K 档（输入 2048）** — 短输入场景
3. **8K 档（输入 8192）** — 长输入压力测试

### 输出长度
固定 1024 tokens（所有档位一致）

### 并发梯度
| 输入档 | 并发梯度 |
|:------|:---------|
| 4096 | 1, 2, 4, 8, 16, 32, 64 |
| 2048 | 1, 2, 4, 8, 16, 32, 64 |
| 8192 | 1, 2, 4, 8, 16, 32 |

### 请求数公式
`planned = clamp(concurrency * 8, 16, 128)`

### 停止条件
- success_rate < 95%
- output tok/s 较峰值明显下降且 P99 暴涨
